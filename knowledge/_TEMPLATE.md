# How this file works
Files starting with _ (like this one) are NOT uploaded. Copy this file, rename it
(e.g. Salerno_Government.md or CivMC_Mechanics.txt) and replace the examples.

Every line starting with "# " starts a new entry. Everything under it, up to the next
"# ", belongs to that entry. The file name becomes the category.

To make the bot read a web page, put it on its own line like this:
I - https://example.com/some-page

To let the bot show a picture, put the file in docs/images/ and add a line like this
(the part after the second dash is an optional caption):
IMG - brunsvik-factory.png - The Brunsvik factory building
